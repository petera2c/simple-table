# Simple Table Starters

Minimal starter templates for [Simple Table](https://www.simple-table.com), a free and MIT-licensed data grid.

## Available Starters

Each starter is a standalone, ready-to-run project that demonstrates Simple Table features like sorting, filtering, and column editing.

### React

A modern React 18 starter with TypeScript and Vite.

- **Local**: [`starters/react`](./react)
- **StackBlitz**: [Open in StackBlitz](https://stackblitz.com/github/petera2c/simple-table/tree/main/starters/react)
- **CodeSandbox**: [Open in CodeSandbox](https://codesandbox.io/p/github/petera2c/simple-table/main?file=/starters/react/README.md)

### Vue

A modern Vue 3 starter with Composition API, TypeScript, and Vite.

## Quick Start

Each starter can be run locally in three steps:

```bash
cd starters/[framework]
npm install
npm run dev
```

## What's Included

All starters include:

- **Full TypeScript support** - Complete type safety
- **Column sorting** - Click headers to sort
- **Column filtering** - Interactive data filtering
- **Column editor** - Right-click menu for column controls
- **Selectable cells** - Click to select cells
- **Modern build tooling** - Vite for fast development
